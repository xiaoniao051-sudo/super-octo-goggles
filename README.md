## 错题库

错题库默认展示统一整理的“阅读解析”。读者把试卷名称、题号或截图发给张菁伟，由他转给 Codex；核对原题后，将完整题干、设问、选项、原创解析及来源一起更新到网站。现已收录28道题：本次图片第6题隐私与便捷性、第16题公共服务（公开整理2022重庆选调43题）；2022年国考行政执法第31、32、34、36、40题；2023年国考行政执法卷13道（含第24题“反觇”思维），2021年新疆兵团卷婚俗填空第48题，粉笔2027年国考第三十九季模考第38、52、63、125、126题，《资料飞升200题》第二篇第7题，以及《练习题27》第1题（书名、版次未显示）。阅读时先显示题面，点击“查看答案与解析”展开讲解。原题、选项顺序及参考解析仍以当前 `answers.json` 为准，不认定为官方标准答案。

读者可搜索试卷、题号、题干、选项和自己的错因，筛选“未弄懂”，在解析里记复盘笔记并标记“已弄懂”。“临时记题”仅作辅助：只填试卷和题号即可，沿用最近试卷，详细信息选填；可存入本机或复制文字，自己在微信发送。网站不自动发送消息，也不调用收费 AI 接口。

公开解析与私人记录分开：公开文件 answers.json 只包含公开题目信息、核验说明及解析；每位访客的错题、草稿、复盘、知识笔记、收藏和掌握进度只保存在自己的浏览器。不同设备和域名不自动同步，换设备前在“我的”备份，随后导入；兼容旧版知识笔记备份。

更新直接发布到固定地址。原有知识卡内容和 ID 保持不变，旧笔记仍可对应原卡片。不作官方押题，不以外部素材代替给定资料。

本仓库仅含公开网站文件，不含原始照片、私人记录、账号凭据或电脑数据。使用相对资源路径，适合项目子路径发布。

## 复习流程第一版

- **独立重做**：选择“独立重做”标签或今日复习入口。列表仅显示试卷、题号和中性状态；提交前不把讲解标题、答案、版本说明、旧作答或笔记插入重做弹窗。选择一个选项，可选“确定 / 犹豫 / 猜测”，点击固定底栏提交后记录本次作答，再显示解析及笔记。跳过不生成作答。
- **连续做题**：“连续做新题”按当前全部未开始且可判分的题生成队列；“开始今日复习”使用到期队列；独立重做列表的“开始连续做题”使用当前筛选结果。提交后点击“继续下一题”，新题隐藏答案并清空选择和把握程度；最后一题点击“完成本轮”返回列表。作答引起筛选结果变化不会改变本轮顺序，未保存的笔记会阻止切题或结束。
- **今日复习**：只安排已开始的错题，未开始的25道可判分题不算逾期，190张知识卡不加入该队列。按作答时本机日历日期，连续答对后依次间隔1、3、7、14天，之后保持14天；同日重复答对不升级，答错重置为次日。日期跨月、夏令时和本地午夜均按日历处理。
- **核验状态**：125材料不全、126关键读数待核、59有争议。这三题可记录选择但 `correct` 为 `null`，不进入到期队列、通过数或正确率。当前其余25题使用本站选项顺序对应的显式参考答案；代码从不解析自由文本 `answer` 推测判分字母。

“已弄懂 / 已掌握”保留原来主观标记的含义，不自动生成作答或代表复测通过。复测通过数按当前核验版本的最近一次有效作答计算；正确率按当前核验版本的累计有效作答计算。题面、选项、判分键或核验依据变化后，旧记录保留但不再参与当前成绩，并要求重新复测。

## 本地验证

运行环境为 Node.js；单元和原有回归测试不需安装依赖：

```sh
npm test
```

禁止启动测试子进程的受限环境可运行：

```sh
node --test --test-isolation=none test-storage.mjs test-questions.mjs test-note-inspection.mjs test-storage-review.mjs test-answer-evidence.mjs
```

`test-browser.mjs` 使用 Playwright 和独立浏览器上下文，默认启动仅监听127.0.0.1的临时静态服务，覆盖桌面及移动窄屏交互，不读取真实浏览器资料。运行 `npm run test:browser`；截图和测试备份写入被Git忽略的 `artifacts/`。本轮仅在本地运行写入合成记录的测试，不在真实线上学习存储写测试数据。线上验收仅作只读核对。

仓库沿用 `main` 分支的 GitHub Pages 自动发布流程（`pages build and deployment`）。发布后应核对部署任务成功、其提交与目标提交一致，并检查线上静态资源和交互。本次入口 `app.js` 和新增 `study-ui.js` 缓存版本为 `20261022-ux`，样式缓存版本为 `20261022-ux24`。

补充 WebKit 兼容检查可设置 `GUOKAO_BROWSER=webkit`（需安装与 Playwright 版本匹配的 WebKit），并按运行环境设置 `PLAYWRIGHT_BROWSERS_PATH`。Windows 上的 WebKit 与 iPhone 触摸/视口配置不等于真实 iOS Safari；真机验收须另行记录 iPhone/iPad 型号、iOS 版本、浏览器、测试网址及结果，不能以模拟检查代替。
