## 错题库

错题库默认展示统一整理的“错题与解析”。读者把试卷名称、题号或截图发给张菁伟，由他转给 Codex；核对原题后，将题目摘要、答案、推理、易错点及来源一起更新到网站。当前等待第一道真实错题，不放虚构占位题。

读者可搜索试卷、题号和自己的错因，筛选“未弄懂”，在解析里记复盘笔记并标记“已弄懂”。“临时记题”仅作辅助：只填试卷和题号即可，沿用最近试卷，详细信息选填；可存入本机或复制文字，自己在微信发送。网站不自动发送消息，也不调用收费 AI 接口。

公开解析与私人记录分开：公开文件 answers.json 只包含已核对的题目信息及解析；每位访客的错题、草稿、复盘、知识笔记、收藏和掌握进度只保存在自己的浏览器。不同设备和域名不自动同步，换设备前在“我的”备份，随后导入；兼容旧版知识笔记备份。

更新直接发布到固定地址。原有知识卡内容和 ID 保持不变，旧笔记仍可对应原卡片。不作官方押题，不以外部素材代替给定资料。

本仓库仅含公开网站文件，不含原始照片、私人记录、账号凭据或电脑数据。使用相对资源路径，适合项目子路径发布。
