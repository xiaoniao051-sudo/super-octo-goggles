## 错题库

错题库默认展示统一整理的“阅读解析”。读者把试卷名称、题号或截图发给张菁伟，由他转给 Codex；核对原题后，将完整题干、设问、选项、原创解析及来源一起更新到网站。现已收录18道题：2023年国考行政执法卷12道，2021年新疆兵团卷婚俗填空第48题，以及粉笔2027年国考第三十九季模考第38、52、63、125、126题。阅读时先显示题面，点击“查看答案与解析”展开讲解。原题、选项顺序及参考解析仍以当前 `answers.json` 为准，不认定为官方标准答案。

读者可搜索试卷、题号、题干、选项和自己的错因，筛选“未弄懂”，在解析里记复盘笔记并标记“已弄懂”。“临时记题”仅作辅助：只填试卷和题号即可，沿用最近试卷，详细信息选填；可存入本机或复制文字，自己在微信发送。网站不自动发送消息，也不调用收费 AI 接口。

公开解析与私人记录分开：公开文件 answers.json 只包含公开题目信息、核验说明及解析；每位访客的错题、草稿、复盘、知识笔记、收藏和掌握进度只保存在自己的浏览器。不同设备和域名不自动同步，换设备前在“我的”备份，随后导入；兼容旧版知识笔记备份。

更新直接发布到固定地址。原有知识卡内容和 ID 保持不变，旧笔记仍可对应原卡片。不作官方押题，不以外部素材代替给定资料。

本仓库仅含公开网站文件，不含原始照片、私人记录、账号凭据或电脑数据。使用相对资源路径，适合项目子路径发布。

## 复习流程第一版

- **独立重做**：选择“独立重做”标签或今日复习入口。列表仅显示试卷、题号和中性状态；提交前不把讲解标题、答案、版本说明、旧作答或笔记插入重做弹窗。选择一个选项，可选“确定 / 犹豫 / 猜测”，提交后记录本次作答，再显示解析及笔记。跳过不生成作答。
- **今日复习**：只安排已开始的错题，未开始的15道可判分题不算逾期，187张知识卡不加入该队列。按作答时本机日历日期，连续答对后依次间隔1、3、7、14天，之后保持14天；同日重复答对不升级，答错重置为次日。日期跨月、夏令时和本地午夜均按日历处理。
- **核验状态**：125材料不全、126关键读数待核、59有争议。这三题可记录选择但 `correct` 为 `null`，不进入到期队列、通过数或正确率。当前其余15题使用本站选项顺序对应的显式参考答案；代码从不解析自由文本 `answer` 推测判分字母。

“已弄懂 / 已掌握”保留原来主观标记的含义，不自动生成作答或代表复测通过。复测通过数按当前核验版本的最近一次有效作答计算；正确率按当前核验版本的累计有效作答计算。题面、选项、判分键或核验依据变化后，旧记录保留但不再参与当前成绩，并要求重新复测。

## 数据与备份兼容

本机键仍为 `guokao-2027-study-v1`，数据格式升级为 `schema:2`，新增 `reviewAttempts`。读取旧 `schema:1` 时仅在内存补空记录，下一次保存才写入新格式；原知识卡、错题和临时记题ID不变。笔记、收藏、掌握标记、随手记、草稿和旧备份合并规则保留。新备份包含作答记录，按稳定作答ID去重；同ID内容冲突时保留双方并提示。无法识别的格式拒绝导入，原数据不变。

旧版本网页不能读取新格式备份。若以后回退代码，应同时保留支持 `schema:2` 的存储读取模块及其依赖，不得清空本机数据。升级前基线为 `a0dd859ae77152e2f02d1db99977cf0fe9caf3fc`，仅作代码比较依据，不应直接将旧存储读取器覆盖回来。

维护题目时，`verification` 为 `{status, note}`，状态仅使用 `checked / pending / incomplete / disputed`，`note` 必须是作答前可见的中性说明。仅证据足够且题面、选项顺序明确的题人工添加 `correctOption`。未设置这些字段的历史题仍可阅读，默认待核，不自动判分。不得用外部材料补编缺失题面。

## 本地验证

运行环境为 Node.js；单元和原有回归测试不需安装依赖：

```sh
npm test
```

禁止启动测试子进程的受限环境可运行：

```sh
node --test --test-isolation=none test-storage.mjs test-questions.mjs test-note-inspection.mjs test-storage-review.mjs test-answer-evidence.mjs
```

`test-browser.mjs` 使用 Playwright 和独立浏览器上下文，默认启动仅监听127.0.0.1的临时静态服务，覆盖桌面及移动窄屏交互，不读取真实浏览器资料。运行 `npm run test:browser`；截图和测试备份写入被Git忽略的 `artifacts/`。部署后可将环境变量 `GUOKAO_TEST_URL` 设为 `https://xiaoniao051-sudo.github.io/super-octo-goggles` 再运行同一测试，报告写入 `artifacts/online/`；仍只使用隔离上下文及合成笔记。

仓库沿用 `main` 分支的 GitHub Pages 自动发布流程（`pages build and deployment`）。发布后应核对部署任务成功、其提交与目标提交一致，并检查线上静态资源和交互。此次页面和模块缓存版本为 `20261020-review1`。

本次验收（2026-10-20，基线 `a0dd859`）：23项自动化测试通过（含三套既有回归），Chrome 155 的1280×900、390×844、320×740交互测试通过。每个视口逐一检查18道题提交前的DOM、旧备份导入、新备份恢复、笔记保留、待核题排除和本地日期到期计算；页面及弹窗内部均无横向溢出、无脚本错误。上海与洛杉矶时区均已测试。移动端为响应式视口测试，未在真实iOS Safari设备验证。
